# Contributing

By intentionally submitting a contribution for inclusion in NoteLah, you agree to license that contribution under this repository's MIT License. You retain ownership of your work. Submit only material you have the right to contribute, and disclose relevant third-party licences and attribution requirements. No copyright assignment is required.

Use synthetic tasks, documents, profiles, and screenshots in tests and examples. Never include real workspaces, resumes, backups, model caches, credentials, or private chat transcripts in contributions. Review both files and Git history before publishing.

Run the checks relevant to your change. When adding or updating a dependency or bundled asset, regenerate notices with `npm run licenses:generate`, inspect the output and licence terms, and update `THIRD_PARTY_NOTICES.md` where needed. A declared licence identifier alone is not a compliance audit.

For security concerns, follow [SECURITY.md](SECURITY.md). See [the release checklist](docs/OPEN_SOURCE_RELEASE.md) before distributing a build.
